Fuente: `/home/renatocarlo19/Descargas/Manual de Identidad Gráfica.pdf`, 19 páginas; texto extraído completo y revisión visual de logotipo, variantes, paleta, tipografía, apoyos y aplicaciones. Fuente del activo: logotipo PNG adjunto por el usuario el 25/09/2026.

- Logotipo original copiado sin redibujar, recortar ni alterar proporciones a `lab/e1/static/company-logo.png`. Se mantiene espacio libre y fondo propio. Se utiliza en acceso, navegación, plantillas y comprobantes nuevos.
- Ámbar visual aproximado `#C68B2D`, hierro `#434345`, perla `#E8E5E2`, obsidiana `#000000`. Las superficies claras derivadas y los colores de advertencia/error son decisiones funcionales de interfaz.
- Inconsistencia documentada: p. 12 etiqueta Ámbar con RGB 202/40/49, que resulta rojo; la muestra y las aplicaciones son doradas. Se siguió el dorado visible, no se presenta como código RGB oficial ratificado.
- Montserrat para texto funcional, con archivos locales y licencia OFL obtenidos del repositorio oficial Google Fonts: https://github.com/google/fonts/tree/main/ofl/montserrat. No depende de internet para mostrar la interfaz.
- Ramona Light se conserva dentro de la imagen del logotipo; no se simuló ni se instaló una fuente propietaria inexistente. Los títulos funcionales usan Montserrat.
- En PDF se incrusta Montserrat para evitar sustituciones y preservar acentos. Logo en proporción original, ticket de 58/80 mm, texto hierro sobre blanco. El uso térmico/monocromo se ensayará con la impresora física.
- Cada operación conserva plantilla/logo históricos; aplicar la nueva identidad no reescribe comprobantes previamente emitidos. Los archivos de muestra adjuntos muestran el diseño nuevo.

La estructura de navegación toma la referencia funcional de Loyverse; los textos, colores, logotipo y organización del negocio corresponden a Frida. Las capturas de Loyverse no se tomaron como instrucciones para copiar módulos ajenos, impuestos, cuentas o datos personales.
